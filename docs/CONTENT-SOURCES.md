## 공식 로고와 사진

신규 방문자용 첫 화면의 `assets/first-round-concept.jpg`는 초보 수강생이 코치의 안내를 받는 분위기를 표현한 생성 사진입니다. 실제 체육관·회원·지도자 사진이라고 주장하지 않으며, 페이지에 콘셉트 이미지라고 표시합니다. 프로그램과 공간 영역은 아래에 적은 실제 수업 영상의 장면을 우선 사용합니다.

사용자 제공 `로고-최종.png`를 원본 픽셀·비율·색상을 보존한 `assets/academy-logo.png`로 사용합니다. SVG viewBox는 투명 여백만 가립니다. 상단·하단·방문 안내·스파링클럽의 학교 링크 및 공식 홈페이지 브라우저 아이콘에 적용했습니다. Sparring Club 자체 브랜드 표시는 유지합니다.

사용자가 제공한 OneDrive 폴더에서 수업 영상을 내려받아 장면을 검토했습니다. 이번 개정에서 실제 수업을 보여 달라는 요청에 따라 성인·학생복싱(`20250102_203627.mp4`), 피지컬 트레이닝(`20250102_192857.mp4`), 키즈복싱(`20250102_153616.mp4`)에서 각각 8초 발췌해 페이지에 사용합니다. 세 프로그램을 엮은 33초 광고에는 이 세 파일과 `20250102_102427.mp4`, `20250102_154311.mp4`, `20250102_174843.mp4`, `20250102_212157.mp4` 일부를 더했습니다. 촬영 시각과 장면 내용으로 분류했으며 파일의 GPS 장소 태그는 확인되지 않았습니다. 공개 저장소에는 압축된 발췌 영상만 올리고 원본은 올리지 않습니다.

앞선 사진 요청에 따라 생성한 단체 훈련 브랜드 이미지는 히어로와 갤러리에 유지합니다. 프로그램 카드와 광고에는 사용자가 이번에 요청한 실제 수업 영상을 사용하며, 어린이 수업 장면도 포함됩니다.

`assets/boxing-wide.webp`와 `assets/boxing-mobile.webp`는 여러 성인 복서가 샌드백·미트를 훈련하는 단체 장면입니다. `assets/academy-training.webp`는 성인들이 코치와 함께 체력운동하는 장면입니다. 모두 ChatGPT 내장 이미지 생성 도구로 만들었습니다. 실제 영상의 붉은 천장·LED·검은 샌드백 분위기를 참고했으며 실제 회원의 동일성을 사용하지 않았습니다. 홈페이지에 AI 브랜드 연출 이미지로 표시합니다.
